# Curio Club Web

Standalone touch-first preschool web game inspired by the structure of curiosity/learning mini-game hubs.

## Current playable build

https://curio-club-web.onrender.com

## Included activities

- Sink or Float
- Space Runner
- Dino Excavator
- Build a House
- Coloring Studio
- Sticker Scene
- Letter Tracing
- Counting
- Shape Sorting
- Music Maker
- Vehicle Sandbox
- Roll or Slide

Also includes a daily reward, collectibles, simulated calls, watch area, parent settings, local progress saving, touch controls and sound feedback.

## Repository status

This repository is now the canonical source location for the Curio Club web project. The current migrated playable build is stored in `bundle/part1.txt` through `bundle/part4.txt`; `index.html` loads those exact source fragments in order. The fragments were SHA-verified after migration. A later cleanup can split the prototype into normal HTML/CSS/JS source modules without changing gameplay.

The current character/art placeholders are original prototype assets and are intended to be replaced during the art pass.
